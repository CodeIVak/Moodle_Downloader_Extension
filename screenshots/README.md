# תיקיית תמונות למדריך

תיקייה זו מיועדת לאחסון תמונות וצילומי מסך למדריך השימוש.

## שימוש עתידי:

אם תרצה להוסיף תמונות למדריך בעתיד:
1. שמור את התמונות בתיקייה זו
2. עדכן את `guide.html` להוסיף את התמונות
3. השתמש בסגנונות ה-`.annotation` להוספת חצים והקפות

## הערות:

- המדריך הנוכחי משתמש באיורים ASCII משופרים במקום תמונות
- אם תרצה להוסיף תמונות, ודא שהן בפורמט PNG או JPG
- התמונות צריכות להיות מותאמות למובייל (responsive)
