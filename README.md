# Moodle PDF Downloader Extension

[![Version](https://img.shields.io/badge/version-1.3.1-blue.svg)](https://github.com/CodeIVak/Moodle_Downloader_Extension)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Chrome](https://img.shields.io/badge/Chrome-88%2B-blue.svg)](https://www.google.com/chrome/)

תוסף Chrome להורדת קבצי PDF והקלטות מדפי קורסים ב-למדא.

**מיועד לסטודנטים באוניברסיטת בר אילן**

## 🚀 התקנה מהירה

### מהקובץ המארז (מומלץ)
1. הורד את [הגרסה האחרונה](https://github.com/CodeIVak/Moodle_Downloader_Extension/releases/latest)
2. חלץ את הקובץ `Moodle_Downloader_Extension_v1.3.1.zip`
3. פתח Chrome → `chrome://extensions/`
4. הפעל "מצב מפתח" (Developer mode)
5. לחץ "טען תוסף לא ארוז" ובחר את התיקייה

### מהקוד המקור
```bash
git clone https://github.com/CodeIVak/Moodle_Downloader_Extension.git
cd Moodle_Downloader_Extension
# פתח Chrome → chrome://extensions/ → טען תוסף לא ארוז
```

## אודות

תוסף זה פותח במיוחד עבור סטודנטים באוניברסיטת בר אילן כדי להקל על הורדת קבצי PDF מדפי קורסים ב-למדא.

## התקנה

1. פתח את Chrome ועבור ל-`chrome://extensions/`
2. הפעל "מצב מפתח" (Developer mode) בפינה הימנית העליונה
3. לחץ על "טען תוסף לא ארוז" (Load unpacked)
4. בחר את תיקיית `Moodle_Downloader_Extension`

## יצירת אייקונים

התוסף דורש שלושה קבצי אייקונים:
- `icons/icon16.png` (16x16 פיקסלים)
- `icons/icon48.png` (48x48 פיקסלים)
- `icons/icon128.png` (128x128 פיקסלים)

### שיטה 1: שימוש ב-Icon Generator

1. פתח את הקובץ `icon-generator.html` בדפדפן
2. לחץ על "צור את כל האייקונים"
3. הקבצים יורדו אוטומטית - העתק אותם לתיקיית `icons/`

### שיטה 2: המרת SVG ל-PNG

1. השתמש בכלי מקוון כמו [CloudConvert](https://cloudconvert.com/svg-to-png) או [Convertio](https://convertio.co/svg-png/)
2. העלה את `icons/icon.svg`
3. המר לשלושה גדלים: 16x16, 48x48, 128x128
4. שמור את הקבצים בשמות המתאימים בתיקיית `icons/`

### שיטה 3: יצירה ידנית

צור שלוש תמונות PNG ריבועיות עם עיצוב של מסמך PDF או כל עיצוב אחר.

## שימוש

1. נווט לדף קורס ב-למדא (lemida.biu.ac.il/course/)

4. בחר להוריד קבצים בודדים או את כל הקבצים בבת אחת

- הסבר על כל תכונה

- שאלות נפוצות (FAQ)

- טיפים וטריקים
